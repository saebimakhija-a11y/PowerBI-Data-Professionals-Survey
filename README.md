# PowerBI-Data-Professionals-Survey-Breakdown
Interactive Power BI Dashboard for a real dataset

Started by cleaning the dataset, containing responses to a survey by professionals in Data-related fields, in Power Query. Used DAX for other calculations.

 Then Built an interactive Power BI dashboard analyzing needful responses. Outlooks such as demographics of survey takers, happiness index in their current jobs, average salaries by countries they reside in, by sex and by job titles were visualized using appropriate charts. Cards display the total number of survey-takers and their average age.
